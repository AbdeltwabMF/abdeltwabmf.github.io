# abdeltwab.xyz

Source code for [abdeltwab.xyz](https://abdeltwab.xyz), my personal corner of the internet.

A place to share what I build, write about what I learn, and document things worth keeping.

## Development

Built with [Astro](https://astro.build/) and deployed to GitHub Pages.

Requires Node.js 22 or later.

```bash
npm install
npm run dev
```

To validate and build the website:

```bash
npm run check
npm run build
```

For adding or editing content, see [CONTENT_GUIDE.md](CONTENT_GUIDE.md).
